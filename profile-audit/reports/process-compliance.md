## Correction in progress

Every PR addition received one fresh, isolated subagent questionnaire using the exact README prompt methodology, question template and freshly generated archetype block. Agents may research their own subject, but cannot read prior answers or vectors. Facts and meaningful contradictions are added before answering. Metadata corrections are applied before questionnaire generation. Evidence and book decisions live in `research/process-review/` and progress only in `STATE.json.personality.expansion.processReview`.

Existing files in `answers/personality/` will not be overwritten. Any accepted independent replacement will be archived under a new dated subdirectory and explicitly selected by STATE.json; original archive hashes are checked. This additive storage preserves the mandatory immutable history when correcting already-archived work. The original validator accepts an explicit answer-file argument, so its checks and thresholds need no alteration. For a revised profile, run `python profile-audit/validate.py personality <id> <activeAnswerArchives[id]>`: the unchanged default lookup still points at the immutable original, so it must not be used as evidence about the replacement.

Original creation order cannot be retroactively claimed. This report distinguishes the original work from the corrective independent review. No profile with an unresolved original-rule blocking validation will be reported as compliant.
